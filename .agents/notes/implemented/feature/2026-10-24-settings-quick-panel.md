# Agent Note: 设置快捷面板与分栏模态窗口

Status: implemented

## Problem

用户要求左栏底部入口先向上弹出包含主题和设置的快捷面板，再通过设置打开大尺寸分栏模态窗口。原来的直接打开方式及紧凑弹窗布局由本篇部分替代；主题持久化、窗口同步和设置路由继续沿用[主题与应用外壳](2026-10-24-theme-and-app-shell.md)。

## Decision

快捷面板使用已安装的 Radix Popover 管理定位、点击外部关闭和键盘焦点。主题行提供暗黑、明亮、跟随系统三个图标选项；设置行关闭面板并打开既有 Dialog，交接时不把焦点抢回入口。普通关闭和模态窗口关闭均恢复入口焦点。

两处主题控件共用一个组件和 Query 缓存，仍只通过可信桥接保存偏好。保存进度和失败状态按相同 mutation key 共享，保存中切换到设置窗口仍禁止重复写入。设置窗口使用浅色导航底座与独立内容面板、宽松的设置行、右上关闭按钮和模糊遮罩；适配暗黑和最小窗口。分类仍为外观、本地引擎、关于，不增加参考图里的未实现功能。

## Alternatives considered

- DropdownMenu 自带菜单键盘导航，很适合动作列表；但主题行包含独立的三段选择，Popover 更适合容纳这类复合控件，避免混合菜单项和单选组的键盘语义。
- 保留大卡片主题选择能同时显示文字说明，但快捷面板需要紧凑图标切换；共用同一个紧凑控件可以保持两处选择、错误和禁用状态一致。

## Consequences

- 常用的主题切换只需打开快捷面板，完整设置多一次点击；两处选择和错误提示共用实现，不引入依赖、IPC 或偏好文件格式变更。
- 大窗口的内容留白较多，但后续设置行可以沿用同一布局；小窗口中的内容面板独立滚动，外框与关闭按钮保持可见。
- 两个 Portal 的焦点恢复需要显式交接，面板打开设置时跳过入口恢复，其余 Esc／关闭行为仍由 Radix 管理。
