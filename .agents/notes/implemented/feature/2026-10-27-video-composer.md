# Agent Note: 视频输入区素材槽位与参数悬浮卡片

Status: implemented

## Problem

文生视频预留空素材栏，底部素材入口和通用参数表单偏离用户参考图，生成方式 Tab 常驻。

## Decision

文生取消空素材栏及添加入口；首尾帧使用独立槽位，支持替换和移除；参考模式顶部展示添加与有序素材。候选来自当前画布节点的当前产物，按模型、角色、数量、媒体元数据和图结构过滤。选取复用连线，保留来源版本同步、撤销和既有本地素材上传管理，不新增文档格式。文生保留不兼容素材移除入口。

参数卡片入口固定为「比例 · 时长」，使用比例图形按钮、清晰度按钮和时长控件；不重复生成方式。保留能力卡与协议规则、待处理参数和声音状态；离散时长不变为连续范围。Tab 只在悬停或单选时显示；空白与其他节点关闭原输入框，操作栏、小地图及弹层不清除选择。

## Related notes

[输入框修复](../../implemented/bug-fix/2026-10-26-canvas-composer-input.md)、[无限画布](../../implemented/feature/2026-10-25-infinite-canvas.md)与本篇部分重叠，保留中文输入、固定下方 620px 布局及撤销。模式切换依照当前实现保留连线，不恢复旧笔记的自动断线。[模型能力演进](../../rejected/architecture/2026-10-27-model-service-experience-and-evolution.md)部分重叠，沿用有效档案与不兼容阻塞。该篇于 2026-10-28 转 rejected，视频方式与参数来源改由[模型服务配置层重构](../architecture/2026-10-28-model-service-rebuild.md)的能力卡与协议规则持有，槽位布局与「比例 · 时长」入口保留。其余搜索命中涉及图片、项目资产或接入路由，与本次布局无关。

## Alternatives considered

- 复制素材到本地引用可冻结选取时版本，但不同于手工连线，来源变化容易产生混淆；复用连线保持一致。
- 固定参考图的参数可直接还原外观，但会暴露模型不支持的值；只改展示，保留能力约束。

## Testing

画布 109 项组件／单元测试通过，新增覆盖文生空栏、尾帧优先选取、无产物与类型筛选、替换撤销及离散时长、比例约束。全仓 lint、typecheck、test 通过。桌面用例覆盖画布选取首帧并生成、中文组字、悬停／选中 Tab、空白与其他节点关闭、缩放与小地图保留选择，以及明暗主题和 720×560 参数卡片边界。

## Consequences

桌面回归一次在重启后本地服务就绪前退出，独立复跑通过；保留这次失败，不把它计为首次通过。CDP 中文组字检查不代替原生输入法候选窗验证。

当前画布包含图片、视频和 TTS 音频节点，音频产物可接入视频参考。视频方式与端口仅来自能力卡和协议规则，支持已声明的编辑／续写待编辑视频槽位；不提供本地音频导入。固定宽输入框仍可能超出窗口；参数卡片单独避让。未引入依赖、文档迁移或供应商请求改动；真实供应商与安装包验收不在本次范围。
