# Agent Note: 画布输入框编辑稳定性与固定下方布局

Status: implemented

## Problem

图片提示词本地输入会先触发菜单状态更新，父组件的文档值尚未同步时，编辑器将 DOM 当成外部变更重建，干扰光标和选区；桌面连续输入 ABC 可复现 BCA。视频受控输入在中文组字期间同步文档，缺少组字保护。输入框自动避让与用户要求的固定下方布局冲突，参考入口和参数栏也偏离参考图。

## Decision

输入过程中保留浏览器维护的 DOM 和选区，以最后渲染的文档值区分本地输入与外部文本变更，只有外部文本或引用展示变化时重建图片编辑器；超长粘贴仍强制恢复文档原文。视频使用非受控 textarea，组字结束后再写入文档，外部撤销仍同步到输入框。取消编辑区焦点高亮，保留文字选择能力。输入框保持 620px 屏幕宽度、固定节点下方，取消视口避让，超出视口通过平移查看。

按用户参考图调整留白、48px 虚线参考框、右对齐复制与字数、紧凑左对齐参数和竖分隔线，使用高度 transition 与减少动态效果偏好。移除常驻空态说明；空提示词仍阻止发送。用户确认保留模型实际字数上限，不添加没有功能定义的 T 按钮。视频继续保留现有参考能力，不新增视频 @ 引用。

## Alternatives considered

- 保留自动避让可以让小窗口内所有控件可见，但会改变输入框与节点的相对位置；用户明确选择固定下方、允许超出视口。
- 重建 DOM 后恢复光标可以统一渲染引用，但普通输入没有必要替换文本节点，且会干扰原生组字与选区；优先保留浏览器 DOM。

## Testing

- 画布 91 项组件与单元测试通过，包含图片文本节点与选区保留、组字保护、视频组字结束写入及撤销。
- Electron e2e 通过逐字输入 ABC、CDP 中文组字与提交、620px 固定宽度及节点下方锚点检查；三张生成、失败重试、视频与引用生成、重启保留回归通过。展开收起高度与 transition、明暗截图由同一桌面用例覆盖。
- 全仓 lint、typecheck、test、format:check 通过。两项重启用例首次运行超时，单独复跑通过；不把首次失败算成通过。

## Consequences

保留 DOM 可避免输入重排和选区丢失，视频组字不再逐字提交中间拼音。固定尺寸输入框可能超出视口，这是用户确认的布局代价。模型与参数功能沿用现有契约，不为复刻外观引入依赖或伪造字数上限。CDP 组字测试不能代替 Windows 原生输入法候选窗验收；本次未检查原生候选窗和加固安装包。
