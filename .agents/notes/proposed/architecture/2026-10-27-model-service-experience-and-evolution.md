# Agent Note: 面向用户配置与模型演进的多模态服务重构

Status: proposed

## Problem

用户购买不同第三方平台的模型 API。当前模型服务把渠道目录格式、模型调用协议、地址继承、能力档案和运行策略同时暴露给用户，普通用户必须理解协议和档案才能完成配置；渠道与模型均可填写地址，却未在四类模型中一致执行。视频能力与渠道型号绑定，后续模型迭代需要修改多个分支；已有特定中转站模板及站点命名的执行判断也不符合平台中立的产品要求。

2026-10-27 用户先确认本篇方案并授权笔记与计划，随后授权实施子计划 03、04；当前 01～04 已实现，05～08 尚未完成。本文覆盖整个父需求，仍保持 proposed；没有修改用户真实数据库或发起真实收费请求。ASR、音乐／音效、声音克隆属于允许评估的条件范围，不是已承诺全部交付。

### 首次方案基线与证据边界

- `packages/contracts/src/models.ts` 的渠道 `apiFormat` 用于目录获取；renderer 也用它作为新文本模型默认协议。真正调用由模型协议决定，不能把渠道目录检查成功解释为媒体生成可用。
- `packages/contracts/src/service-routing.ts` 已含流光、FastAIToken 模板；图片／视频消费模型地址与操作路径，文本只消费地址，`apps/engine/src/modules/generation/adapters/tts.ts` 仍只用渠道地址。
- `apps/engine/src/modules/generation/adapters/video-tasks.ts` 注册 Ark、MiniMax V2、OpenAI multipart、FastAIToken JSON 四种视频实现。MiniMax 默认挂载前缀与去尾 `/v1` 兼容、TTS 去尾 `/anthropic` 不是可推广的地址规则；尚无 Kling、Wan 原生适配器。
- `apps/engine/src/modules/generation/generation.service.ts` 已实现持久任务、调用快照、凭据指纹、恢复、供应商上传和结果归档。上传、幂等恢复等仍直接判断站点命名协议；素材目录 `catalog` 的路由定义不等于能力目录消费已经实现。
- `packages/contracts/src/generation.ts` 的档案同时承载模型能力、协议与调度参数。现有视频参数仍有供应商字段，三种通用模式不能直接代表所有目标型号的操作边界。
- 文本使用独立 pi-ai 流式链路；图片／视频／TTS 使用生成任务。TTS 现有两个同步适配器，尚无完整音色管理及 ASR、音乐、克隆业务入口；TTS 产物时长等元数据仍需补齐。
- 旧笔记中记录的模拟测试、E2E 和构建结果仅代表各自当时的证据；以下基线描述首次提案时源码，03、04 当前实现和本轮重新验证见下一节。没有真实供应商账号调用证据。文档存在、配置合法、目录可访问、某种模式真实生成成功是不同验证层级。

## Proposal

### 产品范围与不可变边界

本轮按用户授权执行子计划 03、04：复用任务 JSON 快照与加密渠道，新增接入及模型定义持久化；模型绑定引用接入，执行前解析并冻结完整配置。增量迁移随功能提供，旧快照只用于恢复，不补造缺失历史。导入先预览，定义更新需显式确认，保存与导入不联网或生成。父需求未全部完成，本文保持 proposed。

1. 用户使用购买的第三方平台 API，包括模型厂商官方云 API 和第三方渠道。不建设本地模型、局域网推理服务、权重管理、GPU 环境或 ComfyUI 接入。
2. 视频首批模型为 Seedance 2.5、Seedance 2.0、Seedance 2.0 Fast、Kling 4.0、Kling 3.0、Wan 3.0、MiniMax H3。七型号是当前交付目录，不是永久写死的 schema 枚举。新模型通过受支持定义扩展，不能借导入旧配置恢复本轮淘汰项。
3. 各接入实际支持的文生、首帧、首尾帧、多模态参考、有声输出均在本轮范围。某型号／渠道不支持的组合不得伪装为可用；尾帧单独输入等能力只有明确支持时开放。
4. 视频编辑、延长、多镜头及 Wan 文档／网页输入只预留操作和专属输入扩展位置，不开放空控件、不承诺已能执行，也不提前扩建通用工作流编辑器。
5. 文本、图片、TTS 均纳入统一管理与地址处理，保留各自执行语义。TTS 的接入、音色管理、测试和真实结果元数据是必交付范围；其他音频能力按下文规则评估。
6. 不内置、推荐或按域名分派某家中转站；用户提供的文档站只是协议差异样本。官方协议名称可以作为契约名称，渠道销售名称不能决定协议或能力。

### 分层职责

以下为概念职责，不预定必须一一增加数据库表或微服务；沿用 Nest 模块、SQLite／Drizzle、共享 contracts、pi-ai 和现有任务内核。

| 对象 | 所有事实 | 边界 |
| --- | --- | --- |
| 渠道 Channel | 用户命名、默认服务地址、加密凭据和请求头、启用状态 | 普通用户配置一次；凭据不进入模型定义或导出包 |
| 服务接入 ServiceConnection | 协议／契约版本、有效地址、操作路由、鉴权、素材交付、目录、幂等与取消策略 | 一个渠道可有多个接入，解决不同域名、协议挂载和凭据需求；默认继承渠道凭据，显式例外仍用加密引用 |
| 模型定义 ModelDefinition | 稳定逻辑标识、精确版本、类别、操作、参数、素材与组合限制、帮助说明及证据来源 | 不绑定特定中转站，不承载轮询和账号密钥；同家族不同版本不自动等同 |
| 渠道模型绑定 ModelBinding | 模型定义、渠道实际模型 ID／路径参数、所用接入、渠道能力收窄、用户默认偏好 | 同一逻辑模型可有多个渠道绑定；不把渠道计费后缀等同官方模型版本 |

目录获取是可选接入操作，不再强制渠道选择四种文本协议之一。拉取结果只形成候选，不自动写库、猜类别或推高能力；目录不可用不阻止手动绑定。保留草稿拉取和事务保存，避免部分保存或载入失败导致误删。

### 面向普通用户的设置

- 渠道基础表单仅呈现名称、默认地址、所需凭据和必要状态。自定义头、协议、目录方式及路由放入渠道的高级接入；普通情况由内置官方／协议方式或校验后导入填充。
- 模型列表显示名称、类别、可用状态和启用开关。选择逻辑模型后自动确定类别与能力，渠道实际 ID 从目录选择或手动填写；不再提供普通模型地址输入或能力档案下拉。
- 同渠道多服务域名、多协议前缀通过高级接入管理，模型仅绑定接入。共享同一接入避免每模型重复地址；编辑时显示影响范围，不改变已提交任务。
- 高级能力页显示当前有效限制及来源，允许有证据的收窄／调整；无法实现的能力不能通过修改限制打开。无依据的未知能力保持未确认，不自动宣称支持。
- 基础界面不铺设解释性段落。复杂字段旁使用 lucide 问号图标和 shadcn 提示，支持悬浮、键盘焦点和点击，提供中文可访问名称。说明包含作用、格式、默认／继承关系和限制；完整 URL、诊断、差异放入按需展开区。
- 表单错误、任务失败、计费操作确认和必须处理的状态就地可见；不能将阻塞信息藏入提示。明暗主题、最小窗口、焦点及禁用状态沿用现有 UI 规范。
- 校验配置、检查目录／权限、真实生成验证分开记录时间与绑定版本。修改相关配置使旧验证状态过期；保存和导入不自动发起收费请求。媒体测试提供明确入口，测试成功仅覆盖实际型号与模式，不能外推整渠道。

### 能力定义与画布动态化

模型能力、适配器可表达能力、渠道限制和当前素材／模式条件共同决定有效能力；既检查范围交集，也检查组合、前置素材及结果类型。渠道覆写不能突破适配器硬边界。调度并发、查询节奏和超时从模型能力中拆出，接入／渠道可限制共享配额，保留必要的模型级收窄。

同一份版本化规则用于 renderer 展示和 engine 强制校验，涵盖操作、参数默认值／单位／取值、条件限制、素材角色／次序／总量、尺寸、时长、格式与编码、声音策略。普通用户不选择内部档案。

视频节点按当前模型绑定的有效能力显示模式、素材入口和参数：不支持的模式隐藏，条件不满足的选项禁用并说明原因。声音区分固定有声、固定无声、可开关，不为固定能力展示无效开关。首帧、尾帧和参考素材分别保存角色及顺序，引用编号和最终请求保持一致。

切换模型保留提示词、原素材与仍合法的语义参数；无法等价迁移的参数标记待选择，不静默替换生成意图。不兼容素材保留并标出问题，阻止提交而不自动删除文件或连线。尚未支持特殊操作时，不根据提示词擅自切到编辑／延长；如上游会推断操作，按契约显式限定本轮操作，无法限定则在提交前处理其参数约束并保留风险说明。

图片保留已有比例／清晰度／画质／背景语义、参考图、单张任务与多结果写回，能力可表达编辑／蒙版差异，不为统一管理把全部图片协议改为同步或强行支持新操作。

### 有限声明式接入与配置导入

内置适配器实现完整协议，声明式配置只补足有限差异：

- 安全相对操作路径、方法、内置鉴权类型、固定协议头。
- JSON 字段重命名／嵌套、固定值、受限类型与枚举转换、声明过的省略规则。
- 素材数组与角色顺序映射、内置 JSON／multipart 编码。
- 任务 ID、状态、错误和产物位置提取，以及已有上传／查询／下载流程的组合。

配置不得包含脚本、任意表达式、循环、动态导入、可执行命令或无限递归；字段选择与转换都有深度、数量、长度和执行边界。未知状态／畸形响应保留不确定性，不默认为成功。复杂签名或新交互流程通过正式适配代码扩展，不扩成通用编程语言。

导入包包含 schema 版本、模型／接入定义、依赖、来源和版本，不含真实密钥、敏感请求头、任务、提示词或素材。来源声明不是可信签名。导入先预览地址、能力、版本冲突及将改变的对象，结构、支持版本、映射目标、网络目标和能力边界全部检查通过后事务保存；失败不留半份配置，不自动访问包中 URL。

导入如携带自定义第三方服务地址，其作用只是用户显式接入，不将该地址写入应用推荐模板。限制内网目标与凭据外发，禁止 URL 内嵌凭据和路径逃逸，下载及返回操作 URL 按接入允许目标校验。配置校验通过不等于账号有权限，也不等于平台认证。

### 地址、执行与任务生命周期

- 统一解析有效连接后交给文本 SDK 和所有媒体适配器；各 SDK 的前缀约定在受测边界处理。地址保留明确部署前缀，操作使用相对路径；新配置不猜 origin、不补删 `/v1` 或 `/anthropic`、不根据域名选择适配器。旧语义只在历史兼容层保存。
- 业务请求使用规范化参数；适配器明确转换 `duration/seconds`、比例、分辨率大小写、嵌套结构、型号路径和素材角色。不能把整个用户参数对象直接展开到所有上游请求。
- 复用现有持久任务内核，将上传、幂等、取消、查询、下载鉴权声明在接入契约；调度器不判断站点名称或站点命名协议。只有有明确幂等保证的提交才允许同键同体恢复；可按外部 ID 查询不等于可以重复 POST。
- 上传独立处理本地资产到文件／内联／供应商文件引用／公网 URL 的交付，优先使用接入已有方式；仅在必须公网 URL 且无适用上传方式时要求对象存储。素材路径来自项目资产，不把本机路径直接发给上游。
- 上传复用绑定内容、接入目标及凭据归属，处理失效和未知结果。不要假定无期限引用永久有效，不承诺不存在的远端清理功能。凭据仅发到明确鉴权操作，外部结果 URL 不自动携带渠道密钥。
- 提交前冻结模型定义版本、接入与适配器契约版本、有效能力、最终参数、素材角色、地址路由及凭据引用／指纹。快照不含明文密钥；配置更新只影响新任务，原凭据不可用时暂停而不换账号。
- 保留提交结果不确定、上传结果不确定、已受理、暂停等待、下载失败等语义。有远端 ID 优先查询，有产物描述优先下载；恢复不重复生成。等待超时不等于远端失败。
- 本地停止等待、请求远端取消、远端确认取消、删除记录和删除资产分别处理。保留部分产物下载进度；队列完成不一定等于生成成功。桌面以轮询为基本交付方式，不要求用户部署公网 webhook。
- 文本保持原生流式／工具调用契约，不强制装成异步视频任务；统一连接、校验、诊断和凭据管理，不宣称本轮引入 Agent 编排。

### 新模型演进与版本管理

模型目录随应用发布，并支持校验后本地导入；本轮不建设远程目录服务或插件市场。模型逻辑 ID、精确版本、渠道别名、能力版本、协议契约版本和已验证绑定分别保存。显式定义和受控别名匹配优先，不按名称包含字符串继承整个模型族能力。

同协议的新视频、图片、TTS 模型，原则上只增加定义、必要映射与绑定；前端通用能力渲染不新增型号条件分支。新增创作操作、复杂签名、新素材载体或新生命周期才增加相应实现，不能宣称任意未来模型仅靠配置即用。

更新前展示能力和接入差异，识别删除／缩小范围等不兼容变化，经确认后只影响新任务；并存旧版本用于历史快照解释与恢复。旧任务若缺少可追溯事实则暂停，不能根据新目录重造历史。扩展验收必须用额外测试定义证明不修改业务 UI 或新增型号分支即可接入现有协议。

### TTS 与条件音频范围

必交付：统一地址与接入、模型能力参数、音色列表／手填 ID／供应商目录（按实际接口）、模型和音色兼容性、试听与测试、任务与归档、真实格式／时长／采样率／声道及可取得的用量。音色归属渠道账号及适用模型，不跨账号误用；缺失时间戳、情感或用量不伪造，不为所有接口假定支持流式输出。

ASR、音乐／音效、声音克隆逐项评估协议证据、业务入口、输入输出、素材隐私／授权、恢复、结果归档及验证成本。能在本轮形成完整可验证交付且不挤占视频／TTS 主线的纳入；否则记录明确技术缺口、顺延条件和后续范围。不能仅新增接口函数或枚举就称完成，也不在未评估前将全部能力排除。评估若引入新的产品取舍，先集中询问用户。

### 迁移与旧配置清理

用户已同意：删除七个目标型号之外的旧视频模型配置、清理对应默认引用；保留历史生成记录、项目文件与已生成资产。文本、图片、TTS 及七型号绑定迁移保留，不误删其他类别或整渠道。旧型号的版本别名／计费 ID 需要按已确认映射识别，不能靠子串把其他变体当作七型号；无法判定的在执行前展示并要求处理。

清理分两阶段：先停止旧型号新建任务并移出可选目录；仍有未完成远端任务时，保留其必要连接、凭据引用和旧解析契约，仅用于查询、下载或用户放弃。任务终结或显式放弃后再清理不再引用的连接，不删除仍被其他模型／任务共用的渠道与密钥。历史记录不提供旧型号重新生成入口，保留可取得的产物恢复；用户放弃不等于远端取消。

缺少历史快照的旧任务不得自动重投；无法确定查询目标时暂停并给出明确处理入口。新增迁移前备份，版本化升级可重入，事务失败不留下部分清理；已分发迁移不改写。普通配置编辑、导入和目录更新不能绕过历史连接保留规则。最初文档阶段未执行清理；当前 03、04 也不代替 07 的旧配置清理。

## Alternatives considered

- **只把现有高级字段折叠并加帮助**：改动最小，可改善首屏；地址语义不一致、站点特例和能力耦合依旧存在，无法支撑新型号的数据化接入，因此同时调整内部职责。
- **渠道统一选一个 OpenAI 兼容格式**：表单最简单，覆盖常见文本平台；样本已经证明视频 JSON／multipart、任务解析和原生协议不同，无法完整表达七型号能力。
- **继续按中转站提供模板和适配分支**：已知平台开箱即用，能最快修某站接入；用户渠道不可预知，维护逻辑会随站点扩散，违背产品平台中立要求。站点样本只用作契约证据。
- **任意用户脚本或通用表达式语言**：适配未知 API 最灵活；执行代码接触密钥、迁移及恢复难验证，复杂度转嫁普通用户，选择有限映射与正式代码适配。
- **任意未来模型全部零代码支持**：更新最方便；新操作、签名、素材载体和生命周期无法由旧能力凭空表达，承诺范围改为现有协议和操作内的数据扩充。
- **本地模型与 ComfyUI**：可覆盖自建开源推理；用户明确产品只使用第三方 API，本轮不建设这一产品面。
- **保留所有旧型号或立即删除全部关联数据**：前者迁移成本低但不符合用户收窄目录要求；后者最彻底但会损失历史和在途结果，采用配置退出与必要连接延迟清理，保留生成记录和资产。
- **建设远程模型目录自动更新**：可快速跟进新型号；额外引入服务、信任和静默行为变更，本轮用应用发布与校验导入，真实更新需求扩大后再评估。

## Acceptance criteria

- 普通配置无需理解 API 格式、操作路径和能力档案；一个渠道地址与凭据可复用，多域名例外在渠道接入管理；高级帮助使用问号提示，错误及计费决策可见。
- 七型号具备证据明确的模式／素材／声音／参数组合矩阵，支持相同模型绑定不同协议和渠道别名；文档、模拟与真实验证分别标识。
- 文本、图片、视频、TTS 的有效地址均来自同一解析边界；普通新配置无域名猜测和补删版本前缀，目录可选，保存／导入事务完整。
- 有限映射拒绝脚本、越界转换、非法目标与能力膨胀；导入可预览、可检测冲突、无密钥、不自动收费；内置运行逻辑无特定中转站模板或站点名分派。
- 视频节点随有效能力动态调整，模式、首尾帧、参考输入、声音及组合限制前后端一致；模型切换不静默丢提示词／素材或替换意图。
- 新视频、图片、TTS 测试定义可在现有协议内仅通过定义／映射接入，不新增业务 UI 型号判断；特殊操作保持未开放，未知契约拒绝执行。
- 任务快照、凭据归属、幂等例外、未知提交／上传、重启、过期引用、共享并发、部分下载和取消均有针对性证据，不重复扣费或外泄凭据。
- TTS 音色、试听、兼容性及真实音频元数据完整；额外音频能力逐项形成纳入交付或明确顺延结论，无空入口或虚构用量／时间戳。
- 旧非七型号配置退出、默认引用清理；历史资产／任务保留，在途连接延迟清理，共享连接不误删，旧型号不能重新生成。临时旧库迁移、失败事务与恢复有测试。
- 代码质量门禁、桌面明暗／窄窗口／键盘、加固产物及实际授权的供应商验证有记录。未验证的渠道、型号和模式显式保留缺口，不以模拟成功代替线上可用。

## Risks

收益是普通用户配置职责清晰、模型迭代可用数据扩充、请求与恢复契约一致；代价是需要跨 contracts、engine、desktop、canvas 和迁移同步，维护版本化能力与协议证据。有限映射不是万能 API 客户端，出现新签名／操作必须扩展代码。

第三方文档可能陈旧或互相冲突，渠道提供的能力也可能不同于官方。首批七型号不能意味着任意渠道所有操作都已联调，账号权限、区域、费用及素材线上效果需单独验证。真实生成需有明确测试账号、范围和费用授权。

旧任务若缺少快照或凭据已失效，无法保证找回远端结果；不伪造历史或自动重投。连接延迟清理会暂时保留旧协议兼容层，其退出条件是相关任务完成或用户放弃，不能变成永久可新建的旧型号入口。

音频扩展成本尚未评估；预留能力不能伪装成支持。新增型号配置虽可导入，来源声明不代表受信任；导入和查询下载的网络及凭据边界必须同样校验。
