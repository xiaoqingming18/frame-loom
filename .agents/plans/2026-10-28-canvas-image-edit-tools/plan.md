# Plan: 画布图片多角度、重打光与表情编辑

Status: done
Note: ../../notes/implemented/feature/2026-10-28-canvas-image-edit-tools.md

## 目标

按关联笔记实现画布图片节点多角度、重打光和表情编辑，固定源图版本、产出独立子节点，并使表情最终合成可以在 engine 任务恢复后安全完成。

## 范围与非目标

- 范围：`packages/contracts` 图片编辑配方与能力、`apps/engine` 表情工件和可恢复合成、`packages/canvas` 图片编辑工具与预览、desktop 宿主 API 和必要 CSP、本项目媒体清理／恢复引用，以及分层定向测试。
- 按用户指示直接复用工作室 BeefTV 项目代码和资源；不做来源、授权或源码许可调查。
- 非目标：普通全局风格系统、多人批量／同图自动合成、每次多图输出、用户／项目持久打光模板、任意本地模型、不兼容协议静默切换、真实收费供应商调用、NSIS 安装卸载和支持矩阵外推。
- 方案边界：界面遵守 Frame Loom 主题和组件；表情最终合成在 engine；生产安全策略只做本地可信资源所需的最小改动；编辑快照固定源媒体 SHA-256。

## 发现与偏差

文档阶段已核对 BeefTV 报告与源码行为：多脸按活动角色单人提交；打光模板为面板实例内存；检测中没有持续可见的手动框选入口；三工具面板状态并非全局互斥不变量。报告中 metadata 完整性及局部区域／颜色校正的文字解释不作为实现依据，按源码与已确认需求执行。实施增加已授权的 sharp；修复 public 资源漏打包、标题遮挡和任务快照中间图媒体引用保护。并发构建影响 E2E engine 启动，构建结束后三项定向复跑通过。
