# Plan: 多角度与重打光工具

Status: draft
Parent: plan.md
Note: ../../notes/proposed/feature/2026-10-28-canvas-image-edit-tools.md

## 目标

在图片节点工具区提供多角度和重打光体验，复刻参数、预览、提示词和各自提交时机，复用现有生成输入框、媒体及可撤销画布操作。

## 前置条件

- 01 完成并提供图片编辑配方、能力及源版本快照契约。
- 阅读 `packages/canvas/src/nodes/views.tsx`、`generation-panel.tsx`、`generation-composer.tsx`、`host.ts`、`commands/commands.ts` 及 `docs/ui-guidelines.md`。
- 原版参数基线：角度默认 45°／0°／4.8／标准镜头；打光默认前向／亮度 50／白光／无轮廓／无风格／智能模式开启。

## 步骤

- [ ] T1 增加图片专属工具入口、工作区状态和兼容模型的显式选择 — 验证：组件测试覆盖源活动版本固定、不兼容时不静默切换。
- [ ] T2 实现多角度参数、六个预设和 CSS 3D 摄像头／天空盒预览 — 验证：纯参数与标签／提示词参数化测试覆盖取整、范围、预设保留距离／镜头。
- [ ] T3 实现 Canvas 2D 光源球、亮度／方向／颜色／风格／智能描述及提示词模板 — 验证：提示词单测断言所有片段和一致性占位符不可删除。
- [ ] T4 完成角度确认即生成、打光创建预填子节点后再由通用输入框发送 — 验证：主路径组件测试断言角度仅提交一次、打光首次确认不发请求且第二次发送成功。
- [ ] T5 将建子节点与来源连线合为撤销事务并保存操作参数 — 验证：画布 store 命令测试断言一次撤销同时移除节点与边。
