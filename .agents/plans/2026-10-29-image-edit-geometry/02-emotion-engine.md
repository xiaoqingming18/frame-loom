# Plan: 表情准备、合成与对齐

Status: done
Parent: plan.md

## 目标

engine 表情链路按冻结的 `geometry` 准备输入、写入请求尺寸、校验输出比例、等比还原并对齐后回贴；符合笔记“表情准备与合成”一节，删除 `fit: 'fill'`。

## 前置条件

- 01 完成，`planEditGeometry` 与配方 `geometry` 可用。

## 步骤

- [x] T1 `generation.service.ts` 创建表情任务时调用 `planEditGeometry`，把 `geometry` 冻结进配方，并用其 `request` 覆盖 `request.params` 中的尺寸字段 — 验证：单测断言 OpenAI 模板下竖图请求体 `size` 与裁切加补边同比例
- [x] T2 `image-emotion.ts` 的 `emotionArtifacts` 按 `crop` 裁切、按 `pad` 用边缘均值补边，蒙版与补边后画布同尺寸 — 验证：像素夹具中裁切图、蒙版尺寸一致且补边色正确
- [x] T3 `compositeEmotion` 增加比例校验：偏差超过 1% 抛出后处理失败，保留 `intermediateSha256`，重试仅重跑合成 — 验证：模拟错误比例返回时任务失败且供应商请求计数不增加，重试后不重复下载
- [x] T4 比例合格时等比缩放并裁掉补边映射回 `crop`；无 `geometry` 的旧任务按等比缩放加居中裁切降级并写诊断 — 验证：补边往返误差为 0；旧配方夹具不再非等比缩放
- [x] T5 实现缩小灰度图上的环带对齐搜索（小范围平移，可选 ±3% 等比缩放），残差超阈值写诊断 — 验证：人为平移 6px 的生成图对齐后与源图环带误差回到阈值内
- [x] T6 收紧椭圆蒙版到眉眼、脸颊与嘴部，保留边缘颜色校正 — 验证：最终图尺寸等于源图，蒙版外像素与源图逐字节一致
- [x] T7 记录高分辨率源图（如 4096×4096）下合成与对齐耗时 — 验证：测试输出耗时，结果写入本计划“发现与偏差”

## 发现与偏差

4096×4096 源图、900×1100 人脸夹具：准备 191ms、合成与对齐 265ms，总计 455ms（Windows、Node.js 24.22.0 单次测量）。仅实现计划要求的小范围平移；±3% 缩放搜索为可选，本期未增加。错误比例停止自动重试轮询，用户重试仅合成。
