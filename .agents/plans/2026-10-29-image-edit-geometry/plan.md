# Plan: 图片编辑输出几何与表情回贴对齐

Status: draft
Note: ../../notes/proposed/bug-fix/2026-10-29-image-edit-geometry.md

## 目标

图片节点的多角度、重打光、表情三项编辑按源图（或表情裁切区域）比例请求输出，任何环节不再非等比缩放；表情最终图尺寸等于源图、蒙版外像素与源图一致，并在回贴前对齐模型产生的小幅偏移。验收标准见笔记 `## Acceptance criteria`。

## 范围与非目标

- 范围：`packages/contracts` 新增几何规划与配方 `geometry` 字段；`apps/engine/src/modules/generation/image-emotion.ts` 与 `generation.service.ts` 的表情准备、合成、比例校验和对齐；`packages/canvas/src/nodes/` 下三项编辑的提交参数、打光子节点尺寸预填、提示词集中与重复实现删除；相关单测与 E2E 模拟场景。
- 基线：`48450d1`。开始实施时重新读取上述文件，不依赖笔记中的行号。
- 非目标：打光光照迁移等效果增强；能力卡格式变更；新增供应商或协议；改动人脸检测、情绪预设和 3D 预览；修改 EditHere；收费供应商调用（真实效果对比需用户另行授权）。

- 关键路径：01 → 02 → 04；01 → 03 → 04。
- 可并行：02 与 03 在 01 完成后互不依赖，可顺序或并行推进。
- 环境：Node.js 24.22.x 与锁定 pnpm；定向测试前先构建 contracts。

## 验收

- [ ] 几何规划在四类能力卡尺寸规则下得到合法且同比例的尺寸，无解时前后端一致拒绝 — 证据：01 单测
- [ ] 表情补边往返无损、错误比例不重发请求、平移可对齐、蒙版外像素不变 — 证据：02 像素夹具测试
- [ ] 角度与打光请求尺寸与源图同比例，打光面板显示预填尺寸 — 证据：03 组件测试
- [ ] 旧画布与无 `geometry` 在途任务可完成且不非等比缩放 — 证据：04
- [ ] 竖图、方图、错误比例三种模拟返回的 E2E 通过；`pnpm run typecheck`、相关 lint、`pnpm run verify` 通过 — 证据：04
- [ ] 笔记移入 `implemented/`，计划转 `done` — 证据：04 收尾提交
