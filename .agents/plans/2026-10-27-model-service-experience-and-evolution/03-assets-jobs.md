# Plan: 素材交付、任务快照与恢复

Status: draft
Parent: plan.md

## 目标

复用持久任务和媒体资产基础，按接入能力处理上传、幂等、查询、取消、下载及共享并发，消除调度器中的站点专属判断。

## 前置条件

- 01、02 完成；接入能力与精确请求契约可用。
- 阅读 `apps/engine/src/modules/generation/generation.service.ts`、`generation.schema.ts`、`media.service.ts`、`public-reference.ts`、`adapters/types.ts`、`apps/engine/src/modules/object-storage`、项目媒体模块及恢复测试。
- 开始实现前核对数据库 journal，新增迁移随当前功能提交，不覆盖用户真实数据库做测试。

## 步骤

- [ ] T1 将上传、幂等、取消、下载鉴权及运行配额声明接到执行器，替换站点命名协议分支 — 验证：相同能力的两个测试接入共用调度，未声明幂等保证不自动重发提交。
- [ ] T2 实现文件／内联／供应商引用／公网 URL 的素材准备与持久复用，按接入和账号隔离 — 验证：未知上传暂停、过期引用更新、无期限引用不被保证永久、无上传能力的 URL 接入才要求对象存储，角色和次序不变。
- [ ] T3 冻结模型、能力、接入、适配契约和最终请求版本，保留加密凭据引用及指纹 — 验证：改地址／型号不改变旧任务目标，换密钥／请求头后暂停，不向新账号查询历史任务，缺失快照不重造历史。
- [ ] T4 完成提交不确定、查询暂停、等待超时、下载失败与部分产物恢复 — 验证：重启及断网情况下调用计数无重复生成，已有远端 ID 只查询，部分下载不整批重跑，产物过期可按协议重查。
- [ ] T5 区分本地放弃、远端取消请求与确认、删除记录和资产；引入渠道／接入共享并发并允许模型收窄 — 验证：排队／运行状态按协议限制取消，多个模型共享额度不超限，等待超时不标为远端失败。
- [ ] T6 统一阶段诊断和受控下载，保留项目离线暂存及恢复写回 — 验证：日志无密钥／提示词／签名查询参数，外部结果无渠道凭据，返回操作 URL／重定向／非法内网目标被正确限制。
