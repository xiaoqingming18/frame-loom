# Plan: 渠道设置、模型管理与校验导入

Status: draft
Parent: plan.md

## 目标

普通用户配置渠道和模型即可使用；高级接入、帮助、导入差异和验证状态有明确入口，移除重复地址与能力档案选择。

## 前置条件

- 01～03 完成，接入、能力、恢复和导入契约稳定。
- 阅读 `apps/desktop/src/renderer/src/features/model-services/model-services.tsx`、`model-defaults.tsx`、`lib/model-queries.ts`、engine channels 控制器／服务／repository 及测试。
- 阅读 `docs/ui-guidelines.md`，复用 `packages/ui` 的 shadcn 与 lucide；先检查已有 Tooltip、Popover、Dialog 能力。

## 步骤

- [ ] T1 实现渠道基础表单与高级接入管理，保留默认地址／凭据继承和必要例外 — 验证：基础表单不要求理解 API 格式，多域名通过接入设置，影响范围可见，无每模型重复地址输入。
- [ ] T2 实现逻辑模型选择、上游 ID 绑定、自动类别／能力及默认模型引用 — 验证：普通表单无能力档案下拉，列表显示可用状态，未知绑定不误启用，七型号目录和新定义扩展走同一 UI。
- [ ] T3 保留草稿目录获取和事务保存，解耦目录方式与调用协议 — 验证：目录不可访问可继续手动绑定，候选不自动入库，模型未加载完不能保存为空误删，失败无部分写入。
- [ ] T4 实现导入校验、地址／版本／能力冲突预览和事务应用，支持已有定义更新确认 — 验证：包中无密钥、非法／未知依赖拒绝、不自动访问或生成，更新不静默影响历史任务，错误可定位。
- [ ] T5 为复杂字段提供问号悬浮／焦点／点击帮助，将长说明和 URL 详情收进按需区 — 验证：无提示段落堆叠，阻塞错误与费用信息仍可见；最小窗口、明暗主题和键盘可操作。
- [ ] T6 分开配置检查、目录／权限检查、按模态实际调用测试，保存验证版本与失效状态 — 验证：媒体测试有明确计费提示，成功仅标记实际绑定／模式，编辑相关配置后旧结果失效，测试使用的草稿或已存版本无歧义。
