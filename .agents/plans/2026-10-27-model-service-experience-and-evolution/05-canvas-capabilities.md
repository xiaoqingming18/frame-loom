# Plan: 画布视频模式、素材与参数动态化

Status: draft
Parent: plan.md

## 目标

视频节点根据当前渠道模型的有效能力调整创作操作、参考入口、参数与声音；切换模型保留用户内容且阻止不合法请求。

## 前置条件

- 01～03 完成；有效能力、规范化请求及任务恢复契约可用，可与 04 在边界稳定后并行。
- 阅读 `packages/canvas/src/nodes`、`registry`、`host.ts`、`store`、`apps/desktop/src/renderer/src/features` 中画布宿主及 generation 查询，以及对应图片／视频 E2E。
- 保留现有图片语义参数、多任务、@ 引用、项目持久化与媒体写回；遵守 `docs/ui-guidelines.md`。

## 步骤

- [ ] T1 将模式、参数和素材入口切换为读取有效能力，区分文生、首帧、首尾帧、参考及声音策略 — 验证：不支持模式隐藏，条件限制置灰且有帮助，固定有声／无声不出现假开关。
- [ ] T2 按操作管理首帧、尾帧、参考图／视频／音频的角色、顺序和引用编号，校验输入与总量 — 验证：七型号代表组合前后端同结果，素材连线与发送请求一致，首尾帧／参考互斥等规则不被 UI 绕过。
- [ ] T3 实现模型切换参数兼容检查和素材保留，明确待选择与待处理状态 — 验证：提示词／文件／连线不静默丢失，合法值保留，无等价参数不静默替换，处理完才可提交。
- [ ] T4 对接统一提交、任务恢复动作、部分结果与本地／远端取消状态 — 验证：切换模型不改变在途任务，重启可继续查询或下载，资产与版本不互相覆盖，失效旧型号无重新生成入口。
- [ ] T5 仅为未来编辑／延长／多镜头／文档输入保留操作扩展接点，不新增空面板；回归图片节点 — 验证：新测试定义无需新增型号 UI 分支，特殊未实现操作不可执行，图片多任务与引用保持正确。
- [ ] T6 检查参数问号帮助、错误定位、明暗主题、小窗口及输入法／键盘交互 — 验证：说明不堆叠，中文组合输入和画布滚轮不被破坏，禁用原因可通过焦点或点击访问。

## 发现与偏差

当前 contracts 的通用 frames 模式允许尾帧，目标型号是否支持单尾帧必须由具体定义限定。素材输入与引用编号属于生成语义，不能仅靠界面隐藏保证合法。
