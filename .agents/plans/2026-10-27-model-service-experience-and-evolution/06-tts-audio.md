## 验证

预期运行 engine TTS／media／generation 相关测试、desktop 音色与试听交互测试、`pnpm run typecheck`、`pnpm run lint`、音频入口 E2E 和 `pnpm run verify`。按真实协议分别覆盖二进制、编码响应、错误和元数据。供应商实际试听结果另记精确绑定与模式。

实际：OpenAI 二进制及 MiniMax hex 通过真实 1 秒 PCM WAV 验证，响应声明 MP3 时归档真实 WAV／16000 Hz／单声道；错误封装、截断音频、奇数 hex 和业务错误拒绝归档。音色账号隔离、旧型号兼容性、精确地址、缺音色提交前拒绝与无用量空值均有测试。Electron 专项覆盖命名保存、显式拉取、收费确认、实际播放、重启保留及 800×800 明暗主题；Escape 可关闭弹层。

最终全仓单元／集成测试 694 项、完整 Electron E2E 18 项通过；typecheck、lint、format:check、build、verify 和 diff 检查通过。已查看真实明暗色截图和音频播放结果；主题断言检查 CSS 颜色，避免只改变原生主题但页面截图未切换。

范围评估：ASR 缺转写操作、文本／分段归档和素材隐私规则，待完整契约后纳入；音乐／音效缺已确认协议、时长／版权参数和业务入口，待绑定与授权证据明确后纳入；克隆缺声音所有者授权、训练及远端删除生命周期，待授权和删除协议完整后纳入。三项均顺延，无空入口；本轮无额外确认纳入项，T6 以完整评估与交接完成。

## 发现与偏差

旧配音页未恢复为并行体系，音色管理与试听融入现有模型服务。音频元数据同时扩展画布严格版本格式，避免媒体上传结果无法保存。接口支持不意味着所有音色可跨模型使用；私有音色按账号及精确型号隔离，旧 `tts-1` 收窄为六种音色。当前未声明情感／语言控制，不展示空参数。
