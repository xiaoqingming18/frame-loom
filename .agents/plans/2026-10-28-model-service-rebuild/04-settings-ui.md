# Plan: 设置页重写

Status: done
Parent: plan.md

## 目标

重写设置中心的「模型服务」和「默认模型」两个页签。交互、文案和布局以下文规格为准，规格来自用户 2026-10-28 确认的原型提示词。重写后用户只需要理解渠道和模型两个概念；能力编辑由 contracts 的能力卡 schema 驱动；地址预览与 engine 实际请求一致。

## 前置条件

- 01、02 已完成。03 未完成时，协议描述为占位内容，表单仍可开发，但能力卡模板内容不完整。
- 阅读 `docs/ui-guidelines.md`、`apps/desktop/src/renderer/src/app/shell/settings-dialog.tsx`（设置弹窗外壳，保持不变）、`lib/engine-client.ts`、`lib/model-queries.ts`、现有 `features/model-services/voice-picker.tsx`。
- 可用组件：`@frame-loom/ui/components/` 下的 button、dialog、dropdown-menu、input、native-select、popover、slider、tabs、textarea、toggle-group、toggle、tooltip。需要 switch、checkbox、table、badge 时，按 `docs/ui-guidelines.md` 的流程用 `pnpm dlx shadcn@4.22.1 add <组件> --dry-run` 生成到 `packages/ui`，替换硬编码颜色，并记录新增了哪些组件。

## 界面规格

设置弹窗外壳、左侧导航和内容区的样式保持现状。

### 视图 1：渠道列表（默认）
- 顶部左侧是标题「模型服务」，右侧是按钮「添加渠道」。
- 渠道卡片显示名称、服务地址（等宽、截断）、各类别模型数（如「文本 2 · 图像 3 · 视频 2 · TTS 1」）、启用开关；渠道下有模型待选协议时，显示黄色徽标「N 个模型待选协议」。点击卡片进入视图 3。
- 空状态：说明文字和「添加第一个渠道」按钮。

### 视图 2：添加 / 编辑渠道
- 左侧是预设列表：中转站 / 自定义、OpenAI、Anthropic、Google Gemini、火山方舟、阿里云百炼、MiniMax、可灵、ElevenLabs。点击预设只填写服务地址和模型列表格式，不带模型。预设表放在 `channel-form.tsx` 内，渠道名称默认取预设名。
- 右侧表单：
  - 渠道名称。
  - 服务地址，下方用小字显示「模型列表地址：<resolveCatalogUrl 结果>」。
  - API Key，可显示或隐藏。编辑时留空表示保留，另有「清除已保存的 Key」勾选。
  - 「高级设置」折叠区：
    - Secret Key，说明「仅 AK/SK 签名类协议需要」。
    - 自定义请求头，键值对，可增删，最多 32 个；已保存的值不可读，编辑时提供「重新设置请求头」。
    - 模型列表格式下拉：OpenAI / Anthropic / Gemini。
    - 渠道并发（1–16）。
- 底部按钮「取消」「保存」「保存并读取模型」。「保存并读取模型」先保存，再进入视图 3 并打开视图 4。服务地址校验错误就地显示。

### 视图 3：渠道详情
- 顶部左侧是面包屑「模型服务 / <渠道名>」，右侧依次是启用开关、「编辑渠道」（进入视图 2）、「删除」。删除需要二次确认，提示「将同时删除 N 个模型，已生成的资产不受影响」。
- 渠道摘要：服务地址、Key 尾号、模型列表格式。
- 工具栏：类别筛选（全部 / 文本 / 图像 / 视频 / TTS）、搜索框、「读取模型」、「手动添加」。手动添加时打开空表单的视图 5，类别默认是文本。
- 模型行：
  - 左侧依次是类别图标、显示名和灰色等宽的上游 ID。
  - 协议徽标，未选协议时为黄色「待选协议」。
  - 能力摘要，由能力卡生成，例如「16 参考图 · 蒙版 · 1K/2K/4K」或「4–30s · 720p/1080p · 首尾帧/全模态」。
  - 最终提交地址：截断显示，悬停看完整地址；有覆盖时加「已覆盖」小标。
  - 启用开关：`blockedReason` 非空时禁用，悬停显示原因。
  - 「测试」按钮、「⋯」菜单（编辑、复制为新模型、导出 JSON、导入到此渠道、删除）。
  - 点击行打开视图 5。
- 「导入到此渠道」：读取 JSON 文件，调用预览接口，显示问题列表，用户确认后批量添加。

### 视图 4：读取模型弹窗
- 加载态显示「正在请求 <模型列表地址>」；失败时就地显示错误分类，例如「鉴权失败：请检查 API Key」。
- 顶部是搜索框和「全选未添加」。
- 每行：复选框、模型 ID、类别下拉（预选推断结果，推断不出显示「请选择」，未选类别不能勾选）、推断的协议（文本显示协议名，图像、视频、TTS 显示「待选协议」）、已添加的显示灰色「已添加」并禁用。
- 底部「添加所选 (N)」，调用批量添加接口。新增模型的能力卡：有协议的用协议模板；没有协议的用该类别的空能力卡，由 contracts 提供 `emptyCapability(kind)`，若 01 未提供，在 01 中补充。添加后关闭弹窗，新行高亮 2 秒。

### 视图 5：模型编辑弹窗
- 叠在设置弹窗之上，约 1080×820；窗口较小时按视口收缩，内容区滚动。
- 顶部标题为「显示名 + 上游 ID」，下方三个标签：「基本信息」「能力与参数」「附加参数」。
- 底部操作栏固定：左侧在有改动时显示「有未保存的修改」，右侧按钮「生成测试」「取消」「保存」。
  - 有改动时关闭或取消，弹出确认框「放弃修改？」。
  - 「生成测试」要求先保存，没保存时禁用并提示「请先保存」。

**基本信息**
- 类别分段按钮：文本 / 图像 / 视频 / TTS。切换时弹确认「将清空协议与能力卡」，确认后协议置空，能力卡换成新类别的空能力卡。
- 上游模型 ID、显示名两个输入框。
- 请求协议：
  - 上方是搜索框，按名称、厂商、路径搜索。
  - 左侧是协议列表，只列 `protocolsForKind(kind)`。每项显示名称、厂商、提交路径（如 `POST /v2/video_generation`）、notes 标签和单选圈。
  - 右侧是协议详情：鉴权方式、标准前缀、全部操作的方法和路径、来源链接。
  - 切换协议时调用 `changeProtocol`。有不兼容字段时弹窗逐项列出，确认后才写入草稿。
- 请求地址：
  - 按操作分行显示 `Model.endpoints` 的草稿预览，在前端用 `resolveEndpoints` 实时计算，例如「提交 POST https://…」「查询 GET https://…」。占位符高亮显示。
  - 下方输入框「使用完整地址覆盖（可选）」。
  - 提示行：推导成功时显示「已根据提交地址推导查询地址」；有 `issues` 时显示黄色提示，并展开「提交 / 查询 / 下载」逐项输入框，只显示协议实际有的操作。
  - 有外部主机时显示红色提示「密钥将发送到 <主机>」，并附确认勾选；勾选后把主机写入 `confirmedHosts`。
- 参考素材传输：仅图像、视频、TTS 显示。图片、视频、音频各一个下拉，选项只列协议允许的值：「自动，按协议处理 / 内联 / 链接（需要对象存储）」。选「链接」且对象存储未配置时，显示黄色提示和「前往对象存储」，跳转设置页签 `storage`。
- 模型并发（可选，只能小于等于渠道并发）。
- 启用开关：`validateModel` 有问题时禁用，并列出原因。

**能力与参数**
- 左右两栏：左栏是能力表单；右栏是「画布参数预览」，宽约 280px，可收起。
- 每个分组标题右侧都有「恢复为协议默认」，调用 `restoreCapabilityGroup`。被用户改过的字段（与协议模板比较）左侧显示 2px 的品牌色竖线；数值输入框的 placeholder 显示「不限」。
- 字段、标签和问号提示来自 `CAPABILITY_FIELDS`；超出协议能力上限的开关不渲染。
- 各类别左栏内容：
  - **文本**：上下文长度、最大输出、输入模态多选、工具调用开关、流式开关、推理档位标签输入、允许发送的采样参数多选。
  - **图像**：
    - 参考图：最大数量、单张上限 MB。
    - 蒙版编辑：开关，加蒙版语义单选（透明区域 / 黑色区域）。
    - 生成数量上限。
    - 尺寸：
      - 发送方式分段按钮，只列协议允许的方式。
      - 档位卡片：每张卡片有启用开关；卡片内是比例网格（1:1、16:9、9:16、4:3、3:4、3:2、2:3、4:5、5:4、21:9），每格显示比例和像素（由 `defaultTierPixels` 计算；`provider` 规则显示「由服务商决定」）。点击格子勾选；点击像素可以手改，改后标记「手动」。网格末尾有「其他比例，如 17:11」输入框和「添加」按钮。
      - 「添加档位」，档位名自由填写。
      - 默认尺寸标签组。
      - 「允许自定义尺寸」开关，打开后显示单边上下限、边长倍数、总像素范围、宽高比上限。
      - 带参考图时的像素上限。
    - 质量：支持值多选和默认值。
    - 透明背景：「支持」「默认」。
    - 返回格式：b64_json / url。
    - 输出格式多选与压缩率。
    - seed、负向提示词、提示词最大字数。
  - **视频**：
    - 生成方式：勾选列表（只列协议支持的方式）和「默认方式」下拉。每个勾选项可以展开：
      - 灰色小字说明使用的素材：文生「无素材」；首帧「首帧 1 张」；仅尾帧「尾帧 1 张」；首尾帧「首帧 1 张 + 尾帧 1 张」；多关键帧「关键帧若干」；全模态参考「参考素材」；编辑、续写「待编辑视频 1 个」。
      - 首帧、仅尾帧、首尾帧、编辑、续写：复选框「可同时带参考素材」，协议不允许混用时不显示。
      - 多关键帧：数量的最少、最多。
      - 全模态参考：复选框组「接受 参考图 / 参考视频 / 参考音频」，以及「可同时带首尾帧」。
      - 协议规则只读：用灰色信息条显示，例如「协议规则：首尾帧模式下画面比例固定为 adaptive」。
    - 参考素材限制：三行表格（参考图 / 参考视频 / 参考音频），列为最多数量、单个上限 MB、单个时长范围（秒）、总时长上限（秒），不适用的格子显示「—」。下方是「所有素材合计上限（可选）」。
    - 输出时长：分段按钮「范围 / 固定值 / 交给模型」。范围模式有最短、最长、步长、默认；固定值用标签输入；「同时允许交给模型」勾选只在协议支持时显示。
    - 画面比例、输出分辨率：标签多选和默认值。
    - 声音：「固定有声 / 固定无声 / 可开关 / 未确认」单选和默认值。
    - 水印：「支持」「默认」。
    - seed、提示词最大字数。
    - 引用语法单选，只列协议支持的语法；起始编号 0 或 1。
  - **TTS**：音色来源多选、预置音色标签（id + 名称）、默认音色、指令文本开关、语速/音调/音量范围与默认值、输出格式与采样率多选及默认值、字数上限、多说话人上限。
- **画布参数预览**：直接复用 `@frame-loom/canvas` 导出的只读参数控件（由 05 提供；05 未完成时先做占位卡片，05 完成后接入），按左栏草稿实时渲染。
  - 图像：模型名、提示词占位、「参考图 0/N」、档位分段（只显示启用的档位）、比例网格（只显示勾选的比例，选中时显示像素）、质量、透明背景。
  - 视频：方式标签（只显示勾选的方式）。选中方式后显示对应素材槽：首帧框；首尾帧为两框加箭头；全模态为「图 0/30 · 视频 0/10 · 音频 0/10」，数量取自参考素材限制；勾了「可同时带参考素材」时，帧框下方再加一行参考素材。底部是「比例 · 时长」卡片，包括比例、时长、分辨率、声音。被协议规则锁定的选项置灰，悬停说明原因。
  - 文本：对话输入框，按输入模态显示附件按钮，推理档位下拉。
  - TTS：文本输入框、音色下拉、语速/音调/音量滑块、输出格式下拉。

**附加参数**
- 参数表格：名称、类型、可选值、默认值、上游字段路径，可增删；路径与协议保留字段冲突时就地报错。
- 「固定请求字段」表格：字段路径、JSON 值。
- 「请求体预览」代码块：调用 `POST /models/:id/preview-request`（02 未提供时在本子计划中补到 engine：用适配器的 `buildSubmit` 生成示例请求，素材用占位，不发送网络请求，响应不含鉴权头），显示示意 JSON 并可复制。草稿未保存时显示「保存后可预览」。

### 生成测试
- 文本：调用 `POST /models/:id/check`，显示两步结果（连接、文本回复）。
- 图像、视频、TTS：先弹确认框「此测试会向服务商发起一次真实生成请求，可能产生费用」。确认后打开测试面板，可选择方式和参数；素材可上传本地文件或留空。提交 `source: 'test'` 的生成任务，显示进度，完成后显示结果（图像、视频预览，TTS 播放器）。结果标注「仅验证当前模式：<方式>」。
- 测试结果写入 `lastCheck`，配置变化后自动失效，由 02 的 configHash 保证。

### 默认模型页
- 四行：文本、图像、视频、TTS，各一个下拉，只列已启用且类别匹配的模型，按「渠道 / 模型」分组。
- 没有可选模型时显示「前往模型服务添加」。
